🎯 SYSTEM OVERVIEW
═══════════════════════════════════════════════════════════════

FLOW:
  1. Order status → delivered (via webhook)
  2. Trigger auto-fills delivered_at = NOW()
  3. Order stays in "Shipped" tab
  4. User sees warning + 2-day countdown
  5. "Ajukan Pengembalian" button available
  6. After 2 days: Cron job auto-completes order
  7. Order moves to "Completed" tab
  8. Return button disappears

AUTOMATION:
  • Trigger: Auto-fill delivered_at when status changes
  • Cron Job: Runs every hour to complete old orders
  • No manual intervention required
